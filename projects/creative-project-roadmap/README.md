# XOTRII Creative Project Roadmap

This roadmap organizes XOTRII creative ideas into portfolio-ready GitHub project concepts. Each concept can become its own repository later with code, screenshots, documentation, and deployment links.

## Project Concepts

| Project | Type | Description |
|---|---|---|
| **xotrii.online** | Portfolio Website | A branded creative technology site with hacker-green UI, animated banners, project cards, audio/video previews, and case studies. |
| **xotrii.exe** | Interactive Web Experience | A game-inspired website concept with boot animations, terminal-style transitions, live wallpaper backgrounds, and cyber UI motion. |
| **XOTRII Card Battle System** | Web Game UI | A card battle interface with aura animations, rank tiers, Japanese/English labels, and collectible character cards. |
| **XOTRII Creates** | Character Customizer App | A creative app concept for building underground rapper-style characters with music, wardrobe, hair, accessories, and profile exports. |
| **Underworld Rapper Fighting Game** | Game Design Concept | A Def Jam-inspired 3D fighting game concept with airport battle stages, character selection, and cinematic presentation. |
| **Handshake Portfolio Build** | Career Portfolio | A professional project showcase designed for Handshake, internships, employers, and academic review. |
| **Academic Credential Portfolio** | Credential Case Study | A professional entry connecting Georgia State University academic work to computer science and creative technology goals. |

## Brand Rules

```txt
Use black backgrounds.
Use hacker green as the main accent.
Keep the layout sharp, structured, and professional.
Make every project feel interactive, not static.
Balance creative identity with employer-ready documentation.
```

## Repository Standards

Every future project should include:

- Clean README with project overview
- Screenshots or mockups
- Tech stack
- Features list
- Setup instructions
- What I learned
- Future improvements
- Portfolio/Handshake summary

## Goal

Turn XOTRII into a professional creative technology brand that shows design taste, programming growth, and original project direction.

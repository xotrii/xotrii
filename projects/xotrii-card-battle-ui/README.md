# XOTRII Card Battle UI

A playable front-end prototype for a collectible card battle interface inspired by competitive game ranking systems and XOTRII cyber branding.

## Purpose

This project demonstrates interactive JavaScript, state updates, UI animation, data-driven rendering, and creative interface design. It is built to show employers that XOTRII can turn a creative concept into a functioning web prototype.

## Features

- Dynamic card rendering from JavaScript objects
- Rarity and rank system
- Selectable battle cards
- Animated aura and hover effects
- Scoreboard logic
- Randomized opponent card
- Responsive layout

## Tech Stack

- HTML5
- CSS3
- JavaScript
- DOM manipulation
- CSS animations

## Recruiter Notes

This project is useful for front-end, UI engineering, creative development, and game interface internship applications because it combines design taste with working code.

## How to Run

Open `index.html` in a browser.

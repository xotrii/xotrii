# XOTRII Internship Portfolio Site

A polished one-page portfolio website built to present XOTRII as a creative technologist, front-end developer, and UI/UX designer. This project is designed for internship applications, remote job outreach, Handshake, LinkedIn, and recruiter review.

## Purpose

This site gives employers a clean way to understand who XOTRII is, what projects are being built, and what technical skills are being developed. The design uses the XOTRII hacker-green brand system while keeping the layout professional and readable.

## Features

- Responsive landing page
- Hacker-green cyber interface styling
- Recruiter-friendly project cards
- Skills and services section
- Contact and social links
- Smooth scroll navigation
- Lightweight vanilla HTML, CSS, and JavaScript

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Responsive web design
- CSS animations

## Employer Value

This project demonstrates front-end layout skills, visual hierarchy, brand consistency, interaction design, and professional project documentation.

## How to Run

Open `index.html` in a browser or deploy the folder with GitHub Pages, Netlify, Vercel, or any static hosting platform.

# XOTRII Online Brand System

**Status:** Concept / Portfolio Case Study  
**Brand:** XOTRII / xotrii.online  
**Style Direction:** hacker-green interface, futuristic underground web identity, Japanese-inspired cyber UI, glitch motion, dark-mode first

## Project Overview

XOTRII Online Brand System is a visual identity and interface direction for `xotrii.online`. The project turns the XOTRII creative identity into a professional digital brand system that can be used across GitHub, Handshake, portfolio pages, website banners, UI mockups, and social media assets.

The design language is built around a high-contrast black and neon-green palette, cyber-terminal visuals, glitch effects, orbital HUD elements, and a game-inspired presentation style.

## Creative Goals

- Build a recognizable visual identity for XOTRII.
- Create a professional portfolio-ready brand direction.
- Use hacker-green UI elements without making the layout feel messy.
- Combine creative design with computer science and front-end development.
- Make the brand feel like an interactive system instead of a flat logo.

## Visual Direction

```txt
Primary Palette: black, neon green, white
Accent Style: digital glow, scanlines, terminal prompts
Typography Feel: bold futuristic display text + clean technical body text
Motion Language: glitch transitions, loading states, hover pulses, scan effects
Mood: underground, sharp, technical, creative, game-inspired
```

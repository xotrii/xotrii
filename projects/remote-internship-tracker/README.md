# Remote Internship Tracker

A front-end productivity dashboard for tracking internship applications, remote job leads, portfolio tasks, and follow-up status.

## Purpose

This project is designed to show practical front-end development skill through a real career-focused use case. It helps organize applications by company, role, status, priority, and next action.

## Features

- Add internship and remote job leads
- Filter by application status
- Track total applications, interviews, offers, and follow-ups
- Save data with localStorage
- Responsive dashboard layout
- Clean recruiter-friendly UI
- Form validation and status updates

## Tech Stack

- HTML5
- CSS3
- JavaScript
- DOM manipulation
- localStorage
- Responsive web design

## Employer Value

This project demonstrates state management, browser storage, UI logic, data rendering, filtering, and practical workflow design. It also directly supports internship and remote job searching.

## How to Run

Open `index.html` in a browser. Data saves locally in the browser through `localStorage`.
